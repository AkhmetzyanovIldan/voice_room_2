# Голосовая «Мафия» для Telegram

Одна реализация сервера: `node server.js`. Команды `npm start`, `npm run dev` и `npm run start:prod` используют те же правила. Старые параллельные реализации TypeScript и заранее собранный `dist` удалены, чтобы способ запуска не менял поведение игры.

## Запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm test
npm run build
npm start
```

Страница: `http://localhost:3000`. Проверка доступности: `/health`.

`npm run build` проверяет синтаксис файлов. Отдельная компиляция не нужна. `npm run format:check` проверяет форматирование; `npm run format` применяет его.

LiveKit Client SDK поставляется из зафиксированных npm-зависимостей через `/vendor/livekit-client.js`, а не из изменяемого CDN URL.

## Настройка окружения

Образец переменных — `.env.example`. Сервер не загружает `.env` автоматически. Для локального запуска с файлом используйте `node --env-file=.env server.js`. В Render задавайте значения в разделе Environment.

| Переменная | Назначение |
| --- | --- |
| `PORT` | HTTP-порт, по умолчанию 3000; Render задаёт свой |
| `LIVEKIT_URL` | WebSocket URL вашего LiveKit |
| `LK_API_KEY`, `LK_API_SECRET` | Ключи LiveKit только на сервере |
| `BOT_TOKEN` | Токен Telegram-бота для проверки подписи initData |
| `REQUIRE_TELEGRAM` | `true` запрещает вход без проверенной Telegram-сессии; по умолчанию `false` для локальной игры |
| `RECONNECT_GRACE_MS` | Ожидание восстановления соединения, по умолчанию 60000 мс |

Без LiveKit можно проверять игру, звуковые эффекты и интерфейс, но голос будет недоступен. Микрофон включается только по действию пользователя в разрешённой фазе. Для воспроизведения звуков браузеру нужно хотя бы одно нажатие пользователя; кнопка «Звук» отключает и голос, и эффекты.

При включении обязательного Telegram-входа задайте `BOT_TOKEN`. В режиме браузерного входа имена являются выбранными пользователем псевдонимами, а не подтверждённой личностью.

**Ключи LiveKit ранее находились в `server/config.local.js` в истории Git.** Файл удалён из текущего дерева и исключён из отслеживания на будущее. Если ключи действующие, перед публикацией их нужно отозвать/заменить в LiveKit и задать новые в окружении Render. Удаление файла не отзывает старые ключи. История Git не переписывалась.

## Правила

- 3–12 мест. Входящий становится наблюдателем. Когда все сидящие готовы и хватает игроков для выбранных ролей, партия начинается автоматически.
- Каждая отмеченная роль входит в колоду один раз; оставшиеся места занимают мирные. В составе обязателен мафиози или дон. Начальный состав, в котором победитель уже определён, не допускается.
- **Дневной голос каждого равен 1.** Очарованный пропускает ближайшее голосование. Условных весов ролей больше нет.
- **Мирные побеждают, когда не осталось живых мафии и дона.** Живой адвокат не препятствует победе. При равенстве сторон или перевесе мафии проверяются доступные мирным спасительные продолжения против лучших действий мафии. Если таких продолжений нет, побеждает мафия. Подробнее: [расчёт концовок](docs/endgame.md).
- При дневном голосовании можно выбрать другого живого игрока или пропустить. Голос фиксируется один раз. При ничьей или отсутствии голосов никто не выбывает.
- Ночь: 20 с. Результат ночи: 5 с. Речь каждого живого по номерам мест: 15 с. Общее обсуждение: 30 с. Голосование: до 30 с. Результат: 3 с. Последнее слово: 15 с каждому выбывшему, если партия продолжается.
- Ночью живой клан мафии (включая адвоката) получает отдельный голосовой канал и закрытый чат. Погибшая мафия только слушает; сообщения ей не доставляются. Мирные и наблюдатели не получают токен ночного канала. В утренней фазе результатов голос отключён всем. Днём обсуждение доступно только живым, последнее слово — указанному выбывшему. Общий чат работает в ожидании, если включён при создании комнаты; ночной чат мафии от этой настройки не зависит.
- При потере соединения место и роль сохраняются на 60 с. По истечении срока или явном выходе игрок покидает партию; победа пересчитывается. Очередь пропускает отключённых выступающих. Перезагрузка той же вкладки восстанавливает сессию через `sessionStorage`.
- После финала раскрывается состав партии; можно готовиться к новой в той же комнате.

### Роли

| Роль | Клан | Действие |
| --- | --- | --- |
| Мафия | Мафия | Выбор жертвы общего выстрела |
| Дон | Мафия | Отдельная проверка «комиссар или нет» и участие в общем выстреле |
| Адвокат | Мафия | Узнаёт точную профессию цели |
| Комиссар (шериф) | Мирные | Узнаёт клан цели |
| Врач | Мирные | Защищает выбранного игрока от убийств этой ночи; себя нельзя лечить две ночи подряд |
| Сержант | Мирные | Один выстрел за всю партию, начиная со второй ночи |
| Журналист | Мирные | Проверяет двух других живых игроков; утром публикуется, совпадают ли кланы, если журналист пережил ночь |
| Любовница (красавица) | Мирные | Лишает цель ближайшего дневного голоса и способностей следующей ночи; действия текущей ночи сохраняются |
| Мирный | Мирные | Нет ночной способности |

У клана один общий выстрел: учитываются выборы живых мафиози и дона, стреляет единственная лидирующая цель. При равенстве выборов выстрела нет. Адвокат не получает дополнительный выстрел. Выбирать себя запрещено, кроме лечения врача; мафия не стреляет в свой клан.

Ночные действия разрешаются одновременно: проверки и очарование, сбор выстрелов/лечения, смерти, публикация журналиста. Поданные проверки дона и адвоката приходят даже при их гибели этой ночью. Если мафия и сержант выбрали одну цель, она погибает один раз; лечение спасает её от обоих выстрелов.

Существующие изображения карт сохранены; подключены `serjant_cart.png` и `jurnalist_cart.png`. История личных проверок доступна вместе с карточкой роли. Правила и описания ролей открываются из меню комнаты.

События добавляются сверху вниз между колонками игроков, с разделителями «Ночь N» и «День N». Лента сохраняется между фазами (до 200 записей в текущей вкладке). Утром при гибели от выстрела воспроизводится короткий эффект. Лечение и визит любовницы сообщаются только их цели, без раскрытия личности действовавшего игрока.

## Устройство проекта

- `server/engine.js`: состояние комнат, правила, фазы, таймеры, голосование и способности.
- `server/roles.js`: определения ролей, клан, первичная проверка победы.
- `server/endgame.js`: конечный граф вариантов концовки и поиск спасительных продолжений.
- `server/index.js`: HTTP, Socket.IO, проверки входных данных, сессии и переподключение.
- `server/media.js`: токены и фактические разрешения LiveKit, синхронизируемые при переходах.
- `server/auth.js`: проверка Telegram initData и нормализация профиля.
- `public/js/ui.js`: интерфейс; получает публичный снимок и отдельное приватное состояние.
- `test/`: правила, полный цикл таймеров, Socket.IO, подпись Telegram и проверка управления LiveKit через подмену SDK.

У каждой фазы есть версия и срок окончания. Ночные действия и голоса принимаются только для актуальной версии и до дедлайна. Фазы результатов закрыты для новых действий. Таймеры отменяются при переходе, завершении или удалении комнаты.

## Развёртывание и границы проверки

Для Render: Build Command `npm ci && npm run build`, Start Command `node server.js`, Health Check Path `/health`. Текущий сервер рассчитан на **один экземпляр**: комнаты хранятся в памяти. Перезапуск процесса/деплой завершает активные комнаты; горизонтальное масштабирование потребует общего хранилища и адаптера Socket.IO. На бесплатном спящем сервисе первый вход может ждать запуска Render.

Автотесты не заменяют проверку реального звука: перед эксплуатацией проверьте разрешение микрофона, смену говорящего, приватность ночного канала, голосование и возвращение после обрыва в Telegram на двух физических устройствах с настроенным LiveKit. Для новых изменений переменные окружения и команда запуска Render не меняются.
