# Проверка изменений

Проверено 14 сентября 2026 года перед отправкой в GitHub.

- `npm test`: 42 теста проходят. Включают расчёт концовок, способности, таймеры, Socket.IO, приватность чата, разрешения LiveKit, гонки переподключения голосового клиента и HTTP-раздачу файлов.
- `npm run build`: синтаксис JavaScript корректен.
- `npm run format:check`: форматирование корректно.
- `git diff --check`: ошибок нет.
- `npm audit --omit=dev`: известных уязвимостей в рабочих зависимостях не найдено.
- Браузер: создание комнаты, выбор состава, посадка и готовность, показ роли, две ночи, утреннее сообщение о лечении, гибель игрока, дневное голосование с пропуском, подтверждение действия любовницы, сохранение ленты между фазами и восстановление сессии после перезагрузки.
- Интерфейс проверен на размерах 390×844 и 320×568. События размещены между колонками игроков, прокручиваются; правила открываются с начала текста. Ошибок в консоли браузера нет.

В ходе проверки устранены гонка между старым и новым голосовыми подключениями, отсутствие очистки неудавшегося подключения, обработка запоздалых аудиодорожек и ложная ошибка при штатном выходе участника из предыдущего канала. Эти случаи покрыты регрессионными тестами.

## Граница проверки

Реальное воспроизведение и разговор через LiveKit на двух физических устройствах не проверялись: локальное окружение не содержит настроенного голосового сервера. Права публикации/прослушивания, изоляция ночного канала и переходы проверены с подменой SDK. После развёртывания следует провести разговор живой и погибшей мафии с мирным наблюдателем на отдельных устройствах, проверив отсутствие ночного звука у мирных и наблюдателей.

Настройки запуска Render не меняются: `npm ci && npm run build`, затем `node server.js`.
